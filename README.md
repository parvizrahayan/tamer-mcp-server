# Tamer Marketplace MCP Server

Multi-seller AI prompt marketplace with x402 payment protocol.

## Endpoint
```
https://agents.tamer-ai.ir/mcp
```

## Usage
Agents can discover and purchase prompts directly using Base USDC via x402 protocol.

- Catalog: `GET https://agents.tamer-ai.ir/agent/catalog`
- MCP: `POST https://agents.tamer-ai.ir/mcp`
- OpenAPI: `GET https://agents.tamer-ai.ir/openapi.json`
